# Security Policy

## Supported version

Security fixes are applied to the latest released Snoon version.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose user data, bypass alarm controls, abuse Android permissions or disclose signing credentials. Use GitHub's **Report a vulnerability** private security advisory for the repository.

Include:

- affected Snoon and Android versions;
- reproduction steps and expected impact;
- logs or screenshots with personal data removed;
- whether the issue affects alarm delivery, Direct Boot, backups or permissions.

Do not attach a keystore, `key.properties`, access token or real backup containing personal alarm data. Acknowledgement and remediation timing will depend on severity and reproducibility.
