# Snoon Privacy Policy

Last updated: August 17, 2026

Snoon stores alarms, alarm groups, sleep schedules, world clocks, application settings, selected language and alarm history only on the user's device. Snoon does not create accounts, display ads, include analytics or tracking SDKs, or send personal data to a server.

## Permissions

- Notification permission is used for upcoming, snoozed and ringing alarm controls.
- Exact alarm access is used to deliver alarms and timers at the time selected by the user.
- Full-screen intent access is used to display alarm controls on the lock screen.
- Vibration is used only when the user enables it.
- Boot notifications are used to restore active alarms and timers after a device restart.
- Foreground media playback is used to keep alarm audio reliable while an alarm is ringing.

## Backups

The user may export Snoon data as a JSON backup file. The user chooses the storage location through Android's system document picker. Snoon does not upload the backup file to any server.

## Data deletion

Alarms and history can be removed inside Snoon. Clearing Snoon's application data from Android settings deletes all Snoon data stored on that device.
